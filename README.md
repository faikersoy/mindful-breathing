# Mindful Breathing

A lightweight breathing and meditation web application designed to support mindful breathing sessions and relaxation.

## Features

- **Breathing Techniques:** 4-7-8 Relaxation, Box Breathing, and customizable breathing intervals.
- **Visual Guidance:** Animated breathing phases with real-time countdown.
- **Ambient Sounds:** Generated rain sounds and ambient audio using the Web Audio API.
- **Walking Meditation:** An alternative mode for mindful walking.
- **Session Controls:** Configurable round counts, start/stop controls, and mute functionality.
- **Bilingual Interface:** Turkish and English language support.
- **Haptic Feedback:** Vibration support on compatible devices.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Web Audio API
- SVG
- CSS Animations

## Getting Started

No build tools or external dependencies are currently required.

1. Clone the repository.
2. Open `index.html` in a modern web browser.
3. Start a breathing session.

## Project Status

Early development / prototype.

The project is being developed incrementally, with a focus on improving timing accuracy, audio lifecycle management, accessibility, and mobile usability.
